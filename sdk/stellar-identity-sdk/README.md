# @wraith/stellar-identity-sdk

Thin TypeScript client for the Stellar identity core contract.

## Core methods

- `init`
- `get_admin`
- `get_prover`
- `set_prover`
- `register_app`
- `update_app_policy`
- `revoke_app`
- `get_policy`
- `is_app_registered`
- `verify_and_record`
- `record_attested_result`
- `is_verified`
- `get_record`
- `has_nullifier`

## Build

```bash
npm install
npm run build
```

## Test

```bash
npm test
```
