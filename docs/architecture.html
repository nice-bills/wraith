Verification Flow

1
Generate ZK Proof
User's application runs the Circom circuit locally with snarkjs, producing a Groth16 proof
↓
2
Convert Proof Format
proof-adapter CLI converts snarkjs JSON proof to Soroban-compatible BN254 format
↓
3
Submit via SDK
TypeScript SDK invokes verify_and_record() on the Soroban contract
↓
4
On-Chain Verification
Contract verifies VK hash, validates proof, checks policy rules, records nullifier + verification record
↓
5
Result Returned
VerificationResult returned to SDK and application; user is now verified on-chain
